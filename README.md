# The Hood Rover
GitHub Pages-ready static website foundation.

Clean routes:
`/` `/collection` `/rover` `/my-rover` `/leaderboard` `/referral` `/roadmap` `/faq`

Mint is OpenSea-only. Replace `OPENSEA_URL` in `assets/app.js` with the real OpenSea collection URL.

Supabase can later power profiles, NFT ownership, missions, quiz state, streaks, spin cooldown/rewards, referrals (max 10), leaderboard and achievements. XP is intentionally excluded and the token is not publicly described.
